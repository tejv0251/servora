## Project description

Built Servora, a self-initiated SaaS for service businesses. It connects customers, quotes, scheduling, jobs, invoices and recorded payments in a responsive React and TypeScript app. Implemented workspace isolation, role-based access, Cloudflare D1/R2 storage, a technician PWA with offline updates, Stripe test-mode integration, automated tests and GitHub Actions. Includes architecture, API documentation and an operations runbook. All business data is fictional.
